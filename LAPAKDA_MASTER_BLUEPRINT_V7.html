Skema Database (ERD - Entity Relationship Diagram)

Berikut adalah bedah lengkap seluruh tabel yang menyusun aplikasi LapakDA.

Tabel users

Menyimpan data Penjual, Pembeli, dan Admin. Login utama menggunakan nomor HP (tanpa email).

  • id: Primary Key.
  • name: Nama lengkap user.
  • nomor_hp: Unik. Dinormalisasi ke format 628xxx.
  • password: Hash password (default acak jika daftar via Guest).
  • is_admin: Boolean. Jika 1, bisa akses panel admin.
  • password_set_at: Waktu user mengatur password sendiri (bukan default).
  • last_latitude & last_longitude: Menyimpan lokasi terakhir (untuk checkout delivery).
Tabel stores

Data toko/resto milik Penjual.

  • owner_id: Foreign Key ke users.id.
  • nama, slug: Nama toko dan URL friendly.
  • kategori: Enum ('resto', 'store').
  • jam_operasional: JSON. Menyimpan jam buka/tutup per hari.
  • active_until: Tanggal kedaluwarsa langganan (subscription).
  • open_fee_paid: Boolean. Menandai apakah biaya buka toko (untuk toko ke-2 dst) sudah lunas.
Tabel orders & order_items

Data transaksi pesanan.

  • user_id: Bisa NULL jika pembeli adalah Guest.
  • session_id: Digunakan untuk melacak pesanan Guest.
  • status: 'menunggu_konfirmasi', 'dikonfirmasi', 'selesai', 'dibatalkan'.
  • chat_expires_at: Waktu kedaluwarsa chat (5 jam setelah pesanan selesai).
  • order_items: Menyimpan harga_saat_beli (snapshot) agar histori tidak berubah jika harga produk naik.
Tabel order_messages

Tabel khusus untuk Fitur Chat Privat.

  • order_id: Foreign Key ke orders.id.
  • user_id: Pengirim pesan (bisa NULL jika Guest yang kirim).
  • message: Teks pesan.
  • image_path: Path gambar (jika mengirim foto).
  • is_read: Boolean (0 = Belum dibaca, 1 = Sudah dibaca). Menjadi kunci Badge Merah.

2 Alur Bisnis (End-to-End)

Alur Pembeli & Guest

Pembeli dapat berbelanja tanpa akun. Data keranjang disimpan berdasarkan session_id browser.

Guest Register (Penting): Jika Guest mendaftar akun di tengah proses checkout, logika di GuestAuthController@register akan memindahkan seluruh pesanan dari session_id lama ke user_id baru. Guest tidak kehilangan pesanan.

Metode Checkout

Di halaman checkout, user memilih:

  • Via WA: Redirect ke wa.me dengan ringkasan pesanan. Bisa dilakukan Guest.
  • Via Chat App: Redirect ke halaman chat internal. Wajib Login.

Alur Penjual & Admin

Penjual mengelola pesanan di Dashboard. Pesanan berstatus menunggu_konfirmasi akan memicu Push Notification ke HP Penjual. Penjual bisa mengubah status menjadi dikonfirmasi lalu selesai.

Admin (SaaS) mengelola platform secara global di AdminDashboardController, memverifikasi pembayaran langganan toko, dan mengelola voucher.

Otentikasi & Normalisasi No HP

LapakDA menggunakan PhoneNumber::normalize() untuk menyeragamkan input user (misal: 0812... menjadi 62812...). Ini penting agar integrasi WhatsApp OTP berjalan lancar.

// app/Support/PhoneNumber.php
public static function normalize(string $nomor): string
{
    $bersih = preg_replace('/[^\d+]/', '', $nomor);
    $bersih = ltrim($bersih, '+');

    if (str_starts_with($bersih, '0')) {
        return '62' . substr($bersih, 1); // 08xx -> 628xx
    }
    if (str_starts_with($bersih, '62')) {
        return $bersih;
    }
    return '62' . $bersih;
}

3 Sistem Chat Privat & Timer

Fitur ini adalah fitur paling kompleks dengan aturan ketat:

  1. Hanya bisa diakses oleh Pembeli (login) dan Penjual.
  2. Jika pesanan selesai, Penjual dilarang chat duluan (harus menunggu Pembeli).
  3. Jika Pembeli chat, Timer 5 Jam (chat_expires_at) berjalan.
  4. Jika Timer habis, chat menjadi read-only (input hilang).

Mekanisme Polling & Unread Count

Frontend menggunakan setInterval setiap 3 detik untuk memanggil fungsi fetchMessages(). Saat endpoint ini dipanggil, backend akan menandai pesan lawan bicara sebagai is_read = 1.

5 Bedah File: ChatController.php

Ini adalah kode utuh dari app/Http/Controllers/ChatController.php. Semua logika validasi timer dan notifikasi ada di sini.

<?php
namespace App\Http\Controllers;

use App\Models\Order;
use App\Models\OrderMessage;
use App\Notifications\NewChatNotification;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Storage;
use Intervention\Image\ImageManager;
use Intervention\Image\Drivers\Gd\Driver;
use Illuminate\Support\Str;

class ChatController extends Controller
{
    public function show(Order $order)
    {
        $this->authorizeChat($order);
        $this->markMessagesAsRead($order); // Tandai dibaca saat room dibuka

        $messages = $order->messages;
        $lawanBicara = (Auth::id() === $order->user_id) ? $order->store->owner : $order->user;

        return view('chat.show', compact('order', 'messages', 'lawanBicara'));
    }

    public function send(Request $request, Order $order)
    {
        $this->authorizeChat($order);

        // --- VALIDASI TIMER & ATURAN CHAT (Hardening) ---
        if ($order->status === 'selesai') {
            // 1. Tolak jika sesi sudah berakhir (lewat 5 jam)
            if ($order->chat_expires_at !== null && now()->greaterThan($order->chat_expires_at)) {
                return response()->json(['error' => 'Sesi obrolan telah berakhir (melebihi 5 jam).'], 403);
            }
            
            // 2. Tolak jika Penjual mencoba chat duluan
            if (is_null($order->chat_expires_at) && Auth::id() === $order->store->owner_id) {
                return response()->json(['error' => 'Tunggu pembeli mengirim pesan terlebih dahulu.'], 403);
            }
        }
        // ------------------------------------

        $request->validate([
            'message' => 'nullable|string|max:1000',
            'image' => 'nullable|image|max:5120',
        ]);

        if (!$request->filled('message') && !$request->hasFile('image')) {
            return response()->json(['error' => 'Pesan tidak boleh kosong'], 422);
        }

        $imagePath = null;
        if ($request->hasFile('image')) {
            $imagePath = $this->prosesDanSimpanFoto($request->file('image'));
        }

        // Simpan pesan
        $msg = OrderMessage::create([
            'order_id' => $order->id,
            'user_id' => Auth::id(), // Bisa NULL jika guest
            'message' => $request->message,
            'image_path' => $imagePath,
        ]);

        // --- LOGIKA NOTIFIKASI CHAT ---
        $isSeller = Auth::id() === $order->store->owner_id;
        $recipient = $isSeller ? $order->user : $order->store->owner;
        
        // Tentukan nama pengirim (Gunakan nama toko jika pengirim adalah penjual)
        $senderName = Auth::check() ? Auth::user()->name : 'Pembeli (Guest)';
        if (Auth::id() === $order->store->owner_id) {
            $senderName = $order->store->nama;
        }

        // Kirim push notification jika penerima valid (Pembeli login / Penjual punya akun)
        if ($recipient) {
            $recipient->notify(new NewChatNotification($msg, $order, $senderName));
        }
        // ------------------------------

        // Logika Timer 5 Jam (Hanya memicu jika order selesai & belum ada timer)
        if ($order->status === 'selesai' && is_null($order->chat_expires_at)) {
            $order->update([
                'chat_expires_at' => now()->addHours(5),
                'chat_initiated_by' => Auth::id() === $order->user_id ? 'buyer' : 'seller'
            ]);
        }

        return response()->json([
            'success' => true,
            'message' => $msg->load('user')
        ]);
    }

    public function fetchMessages(Order $order)
    {
        $this->authorizeChat($order);
        $this->markMessagesAsRead($order);
        
        $messages = $order->messages()->with('user')->get()->map(function($msg) use ($order) {
            // Tentukan nama tampilan: Nama Toko (jika penjual) atau Nama User/Guest
            if ($msg->user_id === $order->store->owner_id) {
                $msg->display_name = $order->store->nama;
            } else {
                $msg->display_name = $msg->user ? $msg->user->name : 'Pembeli (Guest)';
            }
            return $msg;
        });
        
        return response()->json($messages);
    }

    public function badgeCount()
    {
        $authId = Auth::id();
        $storeIds = Auth::user()->stores()->pluck('id');
        
        $pendingCount = Order::whereIn('store_id', $storeIds)->where('status', 'menunggu_konfirmasi')->count();
        
        $unreadChatCount = OrderMessage::whereHas('order', function($q) use ($authId, $storeIds) {
            $q->where('user_id', $authId)->orWhereIn('store_id', $storeIds);
        })->where('is_read', false)
          ->where(function($q) use ($authId) {
              $q->where('user_id', '!=', $authId)->orWhereNull('user_id');
          })->count();

        // Ambil jumlah unread per order_id untuk update badge di halaman riwayat
        $unreadPerOrder = OrderMessage::whereHas('order', function($q) use ($authId, $storeIds) {
            $q->where('user_id', $authId)->orWhereIn('store_id', $storeIds);
        })->where('is_read', false)
          ->where(function($q) use ($authId) {
              $q->where('user_id', '!=', $authId)->orWhereNull('user_id');
          })
          ->selectRaw('order_id, count(*) as count')
          ->groupBy('order_id')
          ->pluck('count', 'order_id');

        // Ambil ID order terbaru untuk deteksi orderan masuk (khusus penjual)
        $latestOrderId = Order::whereIn('store_id', $storeIds)->max('id') ?? 0;
          
        return response()->json([
            'total' => $pendingCount + $unreadChatCount,
            'unread_per_order' => $unreadPerOrder,
            'latest_order_id' => $latestOrderId
        ]);
    }

    private function authorizeChat(Order $order)
    {
        $isBuyer = Auth::id() === $order->user_id;
        $isSeller = Auth::id() === $order->store->owner_id;
        
        // Cek Fallback: Jika pesanan ini milik Guest (user_id null), cocokkan session_id
        $isGuestBuyer = is_null($order->user_id) && session()->getId() === $order->session_id;

        if (!$isBuyer && !$isSeller && !$isGuestBuyer) {
            abort(403, 'Anda tidak berhak mengakses obrolan ini.');
        }
    }

    private function markMessagesAsRead(Order $order): void
    {
        if (!Auth::check()) {
            return;
        }

        $order->messages()
            ->where('user_id', '!=', Auth::id())
            ->where('is_read', false)
            ->update(['is_read' => true]);
    }

    private function prosesDanSimpanFoto($file): string
    {
        $manager = new ImageManager(new Driver());
        $image = $manager->read($file);
        $image->scaleDown(width: 800, height: 800);
        $image->pad(800, 800, 'ffffff');
        $namaFile = 'chat/' . Str::uuid() . '.webp';
        Storage::disk('public')->put($namaFile, (string) $image->toWebp(80));
        return $namaFile;
    }
}

<?php
namespace App\Http\Controllers;

use App\Models\Cart;
use App\Models\Order;
use App\Models\Store;
use App\Notifications\NewOrderNotification;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Str;

class OrderController extends Controller
{
    public function checkout(Request $request, Store $store)
    {
        // 1. Cegah Seller checkout di toko sendiri
        if (auth()->check() && auth()->id() === $store->owner_id) {
            return redirect()->route('store.show', [$store->kecamatan->slug, $store->slug])
                ->with('error', 'Anda tidak dapat melakukan checkout di toko Anda sendiri.');
        }

        // 2. Ambil Cart berdasarkan session_id
        $cart = $this->ambilCartAtauNull($request, $store);

        // 3. Cek Toko Buka/Tutup (Model Store)
        if (!$store->isOpenNow()) {
            return redirect()->route('cart.show', $store->id)
                ->with('error', 'Maaf, toko sedang tutup. Silakan pesan kembali pada jam operasional.');
        }

        if (!$cart || $cart->items->isEmpty()) {
            return redirect()->route('store.show', [$store->kecamatan->slug, $store->slug])
                ->with('error', 'Keranjang kamu kosong, tambahkan produk dulu.');
        }

        // 4. Cek ketersediaan produk
        if ($redirect = $this->cekProdukMasihTersedia($cart, $store)) {
            return $redirect;
        }

        return view('checkout.show', [
            'store' => $store,
            'cart' => $cart,
            'idempotencyKey' => (string) Str::uuid(), // Kunci unik untuk mencegah double submit
            'savedAddress' => auth()->check() ? auth()->user() : null,
        ]);
    }

    public function store(Request $request, Store $store)
    {
        if (auth()->check() && auth()->id() === $store->owner_id) {
            return redirect()->route('store.show', [$store->kecamatan->slug, $store->slug])
                ->with('error', 'Anda tidak dapat melakukan checkout di toko Anda sendiri.');
        }

        // Validasi Input
        $validated = $request->validate([
            'idempotency_key' => 'required|string',
            'checkout_method' => 'required|in:wa,chat', // Pilihan WA atau Chat
            'fulfillment_type' => 'required|in:self_pickup,delivery',
            'dine_in_qty' => 'required_if:fulfillment_type,self_pickup|array',
            'dine_in_qty.*' => 'integer|min:0',
            'table_number' => 'nullable|string|max:50',
            'delivery_latitude' => 'required_if:fulfillment_type,delivery|nullable|numeric',
            'delivery_longitude' => 'required_if:fulfillment_type,delivery|nullable|numeric',
            'delivery_note' => 'nullable|string|max:255',
        ]);

        // HARDENING: Cegah Guest pakai Chat
        if ($validated['checkout_method'] === 'chat' && !auth()->check()) {
            return back()->withErrors(['checkout_method' => 'Silakan login terlebih dahulu untuk menggunakan fitur Chat.'])->withInput();
        }

        // IDEMPOTENCY KEY (Mencegah klik ganda)
        $cacheKey = 'checkout_idempotency:' . $validated['idempotency_key'];
        $hasilSebelumnya = Cache::get($cacheKey);
        if ($hasilSebelumnya) {
            return redirect()->away($hasilSebelumnya); // Langsung redirect ke hasil sebelumnya
        }

        $cart = $this->ambilCartAtauNull($request, $store);

        if (!$store->isOpenNow()) {
            return redirect()->route('cart.show', $store->id)->with('error', 'Maaf, toko sedang tutup.');
        }

        if (!$cart || $cart->items->isEmpty()) {
            return redirect()->route('store.show', [$store->kecamatan->slug, $store->slug])->with('error', 'Keranjang kosong.');
        }

        if ($redirect = $this->cekProdukMasihTersedia($cart, $store)) {
            return $redirect;
        }

        // Logika Pemisahan Dine-in / Takeaway (Khusus Resto)
        $cartItems = array_values($cart->items->all());
        $adaDineIn = false;

        if ($store->kategori === 'resto' && $validated['fulfillment_type'] === 'self_pickup') {
            foreach ($cartItems as $index => $item) {
                $dineInQty = max(0, min((int) ($validated['dine_in_qty'][$index] ?? 0), $item->qty));
                if ($dineInQty > 0) {
                    $adaDineIn = true;
                }
            }
        }

        $wajibIsiMeja = $store->has_table_number && $adaDineIn;

        if ($wajibIsiMeja && empty($validated['table_number'])) {
            return back()->withErrors(['table_number' => 'Nomor meja wajib diisi.'])->withInput();
        }

        // SIMPAN ORDER
        $order = Order::create([
            'store_id' => $store->id,
            'user_id' => auth()->check() ? auth()->id() : null, // NULL jika Guest
            'session_id' => $request->session()->getId(),
            'nomor_order' => 'TEMP-' . Str::random(10),
            'fulfillment_type' => $validated['fulfillment_type'],
            'delivery_latitude' => $validated['delivery_latitude'] ?? null,
            'delivery_longitude' => $validated['delivery_longitude'] ?? null,
            'delivery_note' => $validated['delivery_note'] ?? null,
            'status' => 'menunggu_konfirmasi',
            'payment_status' => 'unpaid',
            'payment_method' => 'cod',
            'platform_fee' => 0,
        ]);

        // Generate Nomor Order Unik
        $order->update([
            'nomor_order' => 'LPK-' . str_pad((string) $order->id, 4, '0', STR_PAD_LEFT),
        ]);

        // Simpan alamat terakhir user (jika login & delivery)
        if (auth()->check() && $validated['fulfillment_type'] === 'delivery') {
            auth()->user()->update([
                'last_latitude' => $validated['delivery_latitude'],
                'last_longitude' => $validated['delivery_longitude'],
                'last_delivery_note' => $validated['delivery_note'],
            ]);
        }

        // SIMPAN ITEMS (Memisahkan Dine-in dan Takeaway jika resto)
        foreach ($cartItems as $index => $item) {
            if ($validated['fulfillment_type'] === 'delivery') {
                $order->items()->create([
                    'product_id' => $item->product_id,
                    'nama_produk_saat_beli' => $item->product->nama,
                    'harga_saat_beli' => $item->product->harga,
                    'qty' => $item->qty,
                    'consumption_type' => null,
                    'table_number' => null,
                ]);
                continue;
            }

            $dineInQty = ($store->kategori === 'resto') ? max(0, min((int) ($validated['dine_in_qty'][$index] ?? 0), $item->qty)) : 0;
            $takeawayQty = $item->qty - $dineInQty;

            if ($dineInQty > 0) {
                $order->items()->create([
                    'product_id' => $item->product_id,
                    'nama_produk_saat_beli' => $item->product->nama,
                    'harga_saat_beli' => $item->product->harga,
                    'qty' => $dineInQty,
                    'consumption_type' => 'dine_in',
                    'table_number' => $wajibIsiMeja ? $validated['table_number'] : null,
                ]);
            }

            if ($takeawayQty > 0) {
                $order->items()->create([
                    'product_id' => $item->product_id,
                    'nama_produk_saat_beli' => $item->product->nama,
                    'harga_saat_beli' => $item->product->harga,
                    'qty' => $takeawayQty,
                    'consumption_type' => 'takeaway',
                    'table_number' => null,
                ]);
            }
        }

        $order->load('items');
        
        // Push Notification ke HP Penjual
        if ($store->owner) {
            $store->owner->notify(new NewOrderNotification($order, $store));
        }

        // Susun Pesan WA
        $pesanWA = $this->susunRingkasanWA($order, $store);
        $waUrl = 'https://wa.me/' . $store->nomor_wa . '?text=' . urlencode($pesanWA);

        // Tentukan Redirect URL berdasarkan pilihan
        $redirectUrl = ($validated['checkout_method'] === 'chat') 
            ? route('chat.show', $order->id) 
            : $waUrl;

        // Simpan URL di Cache (Idempotency)
        Cache::put($cacheKey, $redirectUrl, now()->addHour());

        // Kosongkan Cart
        $cart->items()->delete();
        $cart->delete();

        if ($validated['checkout_method'] === 'chat') {
            return redirect()->route('order.riwayat')->with('success', 'Pesanan berhasil dibuat! Silakan buka chat dari daftar pesanan di bawah.');
        }

        return redirect()->away($waUrl);
    }

    public function riwayat(Request $request)
    {
        $myOrders = collect();
        $incomingOrders = collect();

        if (auth()->check()) {
            $authId = auth()->id();

            // Ambil riwayat belanja (Pembeli) + Unread Count untuk Badge di UI
            $myOrders = Order::where(function($query) use ($request) {
                    $query->where('user_id', auth()->id())
                          ->orWhere('session_id', $request->session()->getId());
                })
                ->with(['store', 'items', 'review'])
                ->withCount(['messages as unread_count' => function($q) use ($authId) {
                    $q->where('is_read', false)
                      ->where(function($sub) use ($authId) {
                          $sub->where('user_id', '!=', $authId)->orWhereNull('user_id');
                      });
                }])
                ->latest()
                ->get();
                
            // Jika user punya toko, ambil pesanan masuk (sebagai penjual)
            if (auth()->user()->stores->isNotEmpty()) {
                $storeIds = auth()->user()->stores->pluck('id');
                $incomingOrders = Order::whereIn('store_id', $storeIds)
                    ->with(['items', 'store', 'user'])
                    ->withCount(['messages as unread_count' => function($q) use ($authId) {
                        $q->where('is_read', false)
                          ->where(function($sub) use ($authId) {
                              $sub->where('user_id', '!=', $authId)->orWhereNull('user_id');
                          });
                    }])
                    ->latest()

        $baris[] = 'Total: Rp' . number_format($total, 0, ',', '.');

        return implode("\n", $baris);

public function isOpenNow()
{
    if (empty($this->jam_operasional)) return true;

    $waktuSekarang = now('Asia/Jakarta'); // Wajib WIB
    $days = ['minggu', 'senin', 'selasa', 'rabu', 'kamis', 'jumat', 'sabtu'];
    $hariIni = $days[$waktuSekarang->dayOfWeek]; 
    
    $jadwalHariIni = $this->jam_operasional[$hariIni] ?? null;

    if (!$jadwalHariIni || ($jadwalHariIni['libur'] ?? false)) {
        return false; 
    }

    $jamBuka = $jadwalHariIni['buka'] ?? '00:00';
    $jamTutup = $jadwalHariIni['tutup'] ?? '23:59';
    $jamSekarang = $waktuSekarang->format('H:i');

    if ($jamBuka <= $jamTutup) {
        return $jamSekarang >= $jamBuka && $jamSekarang <= $jamTutup;
    } else {
        // Handle tutup lewat tengah malam (misal 18:00 - 02:00)
        return $jamSekarang >= $jamBuka || $jamSekarang <= $jamTutup;
    }
}

        $qty = $request->input('qty', 1);

            if ($qty <= 0) {
                $item->delete();
            } else {
                $item->update(['qty' => $qty]);
            }
        } elseif ($qty > 0) {
            $cart->items()->create([
                'product_id' => $product->id,
                'qty' => $qty,
            ]);
        }

        return response()->json([
            'success' => true,
            'cart_count' => (int) $cart->items()->sum('qty'),
        ]);
